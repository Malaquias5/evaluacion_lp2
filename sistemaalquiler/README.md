# Evaluación LP2 - Sistema de Alquiler de Películas 🎬

Este proyecto es parte de la evaluación del curso de Lenguaje de Programación II. Se trata de una aplicación para gestionar clientes, películas y alquileres.

Tecnologías Utilizadas
- Java 17
- Spring Boot 3
- Spring Data JPA
- Thymeleaf
- MySQL
- Git y GitHub

## Entidades
- Cliente
- Película
- Alquiler
- Detalle de Alquiler

## Estado del alquiler
- `ACTIVO`
- `DEVUELTO`
- `RETRASADO`

## Base de Datos
Nombre: `Peliculas`
Incluye script de creación en `/script-bd.txt`
